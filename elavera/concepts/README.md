# Резервные концепты (не часть каталога)

В этой папке лежат 12 кадров из присланных архивов, которые **не соответствуют ни одному из 16 изделий каталога**. Они сохранены как концепты для возможных будущих коллекций.

**Правила:**
- Кадры **не подключены** к сайту: папка лежит вне `public/`, ключей в `public/images/manifest.json` нет, `npm run import-images` их не трогает.
- Для них **нет** названий, артикулов, цен, характеристик и описаний — и они не создаются.
- Использовать их (в каталоге, баннерах или новых коллекциях) можно **только после отдельного согласования**.
- Они не заменяют недостающие фотографии изделий (№ 17, 18, 20, 21, 22 из `IMAGE_GENERATION_BRIEF.md`).

Файлы: `concept-01.webp` … `concept-12.webp` (WebP, качество 92, исходные пропорции). Размеры — в `index.json`.
