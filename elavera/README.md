# ÉLAVÉRA — Fine Diamond Jewelry

Концептуальный демонстрационный сайт ювелирного дома: Next.js (App Router) · TypeScript · Tailwind CSS 4 · Lucide · Motion.

## Запуск

```bash
cd elavera
npm install
npm run dev          # http://localhost:3000
npm run build && npm start   # production-сборка
npm run lint         # проверка типов
```

## Страницы

| Маршрут | Назначение |
|---|---|
| `/` | Главная: Hero, коллекции, избранное, Editorial, Signature «Lumière», философия, финал |
| `/collections` | Каталог (16 изделий): фильтры, сортировка, фильтры в URL, избранное, быстрая покупка |
| `/product/[slug]` | Карточка: галерея + увеличение, металл, размеры и таблица, характеристики, похожие |
| `/maison` | Имиджевая страница: история, свет, макро, процесс |
| `/checkout` | Корзина и демо-оформление (оплата не подключена, средства не списываются) |

Корзина открывается боковой панелью с любой страницы; корзина и избранное хранятся в `localStorage`.

## Изображения (важно)

Изображения создаются вручную в ChatGPT по `IMAGE_GENERATION_BRIEF.md` (22 задания; машиночитаемый список — `IMAGE_MANIFEST.json`). Платные вызовы API не используются. Пока файла нет, сайт показывает честную иллюстрацию-заглушку.

```bash
# 1. положите PNG/JPG с именами из ТЗ в elavera/incoming-images/
npm run import-images             # конвертация в WebP + запись в public/images/manifest.json
npm run import-images -- --dry    # сухой прогон, ничего не пишет
```

- Товарные фото показываются **целиком** (`object-contain`); фон под фото берётся из цвета краёв снимка (поэтому края кадра должны быть ровного #F5F1EA). Баннеры и editorial — `object-cover` с индивидуальным `object-position`.
- Галерея товара показывает только существующие ракурсы. Чтобы добавить ракурсы, импортируйте `<slug>-2.png` и `<slug>-3.png` — они появятся автоматически; блок Signature использует первый доступный ракурс.
- `npx tsx scripts/build-brief.ts` пересобирает ТЗ и манифест из `src/lib/products.ts`.

## Что нужно для реального магазина

CMS/PIM вместо `src/lib/products.ts` (`getProducts()` — единая точка замены) · платёжный провайдер (Stripe/Adyen и т. п.) и серверное создание заказа · расчёт доставки и налогов · учёт остатков · почтовый сервис для рассылки и подтверждений · реальные сертификаты камней и юридические тексты (доставка, возврат, оферта) · реальные контакты и соцсети · аналитика и согласие на cookie.
