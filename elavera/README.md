# ÉLAVÉRA — Fine Diamond Jewelry

Концептуальный демонстрационный сайт ювелирного дома: Next.js (App Router) · TypeScript · Tailwind CSS 4 · Lucide · Motion.

## Запуск

```bash
cd elavera
npm install
npm run dev          # http://localhost:3000
npm run build && npm start   # production-сборка
npm run lint         # проверка типов
```

## Страницы

| Маршрут | Назначение |
|---|---|
| `/` | Главная: Hero, коллекции, избранное, Editorial, Signature «Lumière», философия, финал |
| `/collections` | Каталог (16 изделий): фильтры, сортировка, фильтры в URL, избранное, быстрая покупка |
| `/product/[slug]` | Карточка: галерея + увеличение, металл, размеры и таблица, характеристики, похожие |
| `/maison` | Имиджевая страница: история, свет, макро, процесс |
| `/checkout` | Корзина и демо-оформление (оплата не подключена, средства не списываются) |

Корзина открывается боковой панелью с любой страницы; корзина и избранное хранятся в `localStorage`.

## Изображения (важно)

В окружении разработки не было ни MCP-инструмента генерации, ни `OPENAI_API_KEY`, а разрешения на платные вызовы не давалось, поэтому **фотографии не сгенерированы**. Пока файла нет, сайт показывает честную иллюстрацию-заглушку; когда изображение появляется в `public/images/manifest.json`, оно подхватывается автоматически (во всех местах сразу: каталог, карточка, корзина).

```bash
cp .env.example .env            # задайте OPENAI_API_KEY (не коммитить)
npm run images                  # сухой прогон: список и число вызовов, без трат
npm run images -- --yes         # 22 обязательных: 2 Hero, 4 editorial, 16 товаров
npm run images -- --yes --all   # + 3 макро и 18 доп. ракурсов (правка от основного снимка)
```

- Промпты и имена файлов: `image-prompts.json` (пересборка: `npm run prompts`, источник — `scripts/build-prompts.ts`).
- Названия моделей (`IMAGE_MODEL_ART`, `IMAGE_MODEL_CATALOG`) берутся из окружения; проверьте их актуальность в документации OpenAI.
- Ключ используется только в скрипте, не во frontend-коде. Результат: `public/images/**.webp`.

## Что нужно для реального магазина
